# Web server

Setting up an Nginx web server on Ubuntu with Bash scripts that run without human intervention.

- `0-transfer_file`: copies a file to a server's home directory with scp
- `1-install_nginx_web_server`: installs Nginx on port 80, serving a page with Holberton School
- `2-setup_a_domain_name`: my domain name, pointing to my web-01 server
- `3-redirection`: task 1 plus a 301 redirect on /redirect_me
- `4-not_found_page_404`: task 3 plus a custom 404 page
